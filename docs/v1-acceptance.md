# 微光数学 V1 验收与维护

产品版本固定 V1；提交 SHA 识别实际部署。禁止在未通过真实验收时把测试环境通过称为生产完成。

## 自动化检查
- CI: Python 单元/集成测试、TypeScript/Vite、手机/电脑/编辑器浏览器场景、PDF 实际页面尺寸、部署脚本。
- AI 工作记录：计划最终成果工具、每项实际业务成功结果、未解决失败、续作额度；仍须人工核对任务语义是否与用户要求一致。
- 上传：200 MiB 单文件，后端、Nginx 同步；文档导出数据仍为 200 MB。
- 系统设置：磁盘警告、加密快照大小、视频快照覆盖状态、只读异常残留检测。

## 必须执行的实际验收
1. 在生产 HTTPS 上测试正常资料、接近 200 MiB 原始资料、超过 200 MiB 拒绝；验证手机上传与审核同屏。
2. 用真实 Qoder 账号执行聊天检索、工作组卷、失败续作，验证真实工具结果、局部修改、重复写保护；聊天、视频、工作并发时检查排队和取消。
3. 用不同来源、跨页资料录入、查重、知识点/知识标签分离，检索及统计、组卷分值、教材增题、文档模板和 PDF 预览导出、作品两版本、封面。
4. 使用真实题目完成视频生成、校验、渲染、局部微调、归档和下载；确认独立引擎的实际源码与产物。
5. 由管理员激活视频快照并触发主备份；核对私有仓库、密文清单和视频状态。用离线 age 密钥在独立空数据库及新文件目录完成真实恢复，独立视频库核对恢复路径、源码和成片。禁止在生产直接演练恢复。
6. 确认 HTTPS、服务器容量、备份定时器及异常告警；公开仓库生产 Runner 仅允许可信代码，部署权限和密钥隔离需管理员在 GitHub 设置确认。

## 维护原则
不为清洁代码进行无收益的大规模重构。大文件按业务边界渐进拆分，CSS 先有桌面/手机视觉回归基线再移除兼容层；不得破坏已验收交互。依赖升级基于实际漏洞扫描及回归测试。正式上线以验收结果为准，不以文档承诺代替结果。

首次部署后，管理员可通过 `sudo bash ~/jiaoyan-app/current/deploy/v1-activate.sh` 一次激活实际 HTTPS 上传限制、独立视频快照及提交现有主备份。脚本只在唯一匹配站点时自动选择，不修改其他站点；引擎忙时拒绝快照，请在空闲时执行。状态必须以实际仓库及系统设置为准。

十万题检索压力测试已于 V1 收尾阶段通过，按产品负责人要求不再在日常 CI 或部署中重复执行。保留原测试代码，仅在明确需要时手动运行 `cd backend && python -m pytest -q -s tests/test_question_search_scale.py`（须使用独立测试数据库并按测试要求设置环境）。
