# 01.10 验收清单

当前状态：自动化测试已编写，真实运行结果待核实；服务器 Runner 此前已注册，但尚未证实本次执行成功；尚未完成 HTTPS、管理员创建和实际手机操作。禁止把代码提交标记成验收通过。

## 自动检查
- CI: Python 3.10/3.12，PostgreSQL 16 隔离数据库，迁移一致性、认证、上传/下载/查重/归档恢复、设置、SPA 路由、前端构建、部署脚本语法。
- Server preflight: Runner 非 root、磁盘、数据库及 systemd 状态、本地应用健康。只读诊断，不改服务器。

## 首次上线
- 在服务器上执行 bootstrap，使用真实 HTTPS origin；确认现有数据库不会被覆盖。
- 配置域名或受信任 TLS 访问入口及 Nginx，检查 443 端口与安全组。
- 在 GitHub 仓库启用 ENABLE_DEPLOY=true，手动运行 CI；成功后初始化管理员。
- 打开 HTTPS 地址，完成下列人工测试。

## 手机/电脑验收
1. 首页可加载；未登录直接访问业务 API 返回 401。
2. 登录成功、刷新保留登录状态、退出后无权限。
3. 上传一个 TXT 和一张 PNG，查重、图片预览、下载、归档恢复。
4. 公式预览检查极限、矩阵、方程组、多行等号及错误提示。
5. 修改主题及名称，刷新检查设置持久化。
6. 查看版本、存储统计、日志；确认移动端布局。
7. 备份文件与数据库在隔离环境恢复演练；用测试数据验证版本更新不丢失。
8. 受控测试重启后恢复、失败版本回滚。不得在有重要业务数据时盲目模拟失败。

未实现/未验收：Logo 与语言选择、文件安全扫描和总容量配额、备份恢复演练、部署及实际手机测试。视频与完整 AI 模型认证仍暂缓。
