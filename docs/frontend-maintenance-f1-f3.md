# 前端 F1–F3 维护基线

目标：保留已验收的黑白灰 ChatGPT 式工作空间、原 Logo、桌面 Word / 手机卡片、数学排版与现有业务接口。禁止借清理改动业务数据或恢复已退役的页面。

## F1
- navigation.ts 的 modules 是路由元数据，workspaceGroups 是当前唯一侧栏业务分类；旧分组、顶部内部导航和未挂载旧页面移除。历史 URL 重定向仍保留在 App.tsx。
- 商品售卖页面可进入，但 ready=false，明确没有订单、收入或上架功能。
- 旧 MobileDocWork 实现不再被运行时引用；CardPanel 类型迁入 DocWork，真正编辑器仍是 ManualIntakeCards。
- 保留仍有规划价值的独立组件，避免将尚待接入的实现和已退役页面混为一谈。

## F2
- theme.css 统一颜色、侧栏宽度、弹窗尺寸和公共设计 token，保持原有数值。
- main.tsx 按基础、业务、最终覆盖分组样式，保留原 import 顺序。不进行未经截图回归验证的全局级联重写。
- 业务弹窗保留 300px 紧凑宽度和明暗主题，支持原因输入、空白禁止提交、取消/ESC、焦点恢复。
- 保留独立的白色 A4 打印样式、封面导出和原始品牌资源。

## F3
- WorkspaceConfirm 负责业务确认及原因输入；不使用浏览器原生 confirm/prompt。关闭网页/刷新时的 beforeunload 是浏览器安全机制，无法自定义。
- WorkspaceNavigation 保护聊天、AI 录入、审核与 Word 未保存状态，覆盖侧栏、模式切换、相关页面链接及浏览器历史 POP；内部保存/提交后的路由变更由原业务控制。
- 验收：既有浏览器测试外，新增聊天/工作草稿取消离开仍保留内容、导入内容确认清除的断言。CI 与实际页面截图仍须核验，不将静态检查视为通过。
