# V1 统一答案与解析规范

- 数据结构继续使用 question_data v1，兼容原有 answer/solution 文本、题库查重、视频推荐方法及历史文档。禁止批量重写旧题。
- AI 生成的答案只写最终结果；解析写考试卷面规范的完整推导。多小问分开保存，多个方法仅一个推荐。原文已有数学内容保持不变。
- 审核、题库详情、录入文档和打印/PDF 使用共享答案解析展示，自动加字段标题、分组和推荐解法标识。审核可折叠，默认展开；AI 来源标记仅审核显示。
- 兼容旧题不确定的小问结构，保留其原文本展示，不猜测小问对应关系。旧思路字段不改写或删除，不单独展示为题目解析模块。
- 审核中可重新生成缺失或 AI 生成的解析；成功后仅更新解析并撤销当前题通过状态，失败保留旧解析，原文解析只可人工修改。未改动原题数据库与导出模板参数。
