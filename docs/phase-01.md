CI 在 GitHub 托管运行器上使用独立 PostgreSQL 测试库执行后端测试及前端构建；尚未核实实际运行结果。CI 不执行生产部署，不连接华为云。前端锁文件尚未生成，暂用 npm install；后续提交锁文件后使用 npm ci。

单管理员账号通过服务器命令初始化；不提供公开注册接口。密码用 Argon2id 哈希，会话使用数据库中的随机令牌摘要，Cookie HttpOnly/SameSite=Strict，生产环境 Secure。状态变更要求同源 Origin。失败尝试通过数据库行锁控制，单管理员全局锁定可能被恶意尝试触发，正式部署时增加反向代理限速。
