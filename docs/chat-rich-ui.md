# 聊天输出与交互卡片 v1

仅 Chat 页面使用 RichChat，其他业务页仍使用原 MathText。普通回答采用 Markdown/GFM + KaTeX，禁用原始 HTML、远程图片和模型自定义链接。模型可选 wg-card JSON 围栏，支持 comparison、steps、plot（受限二次/三次函数）、bar、tasks、documents、videos，解析失败不执行任何内容。条形图为 AI 提供数据，不宣称实时统计。真实资源卡由本次用户消息的后端 resource_refs 决定，按需获取现有资源接口；视频操作进入已有工作台，录入仍由原确认链执行。任务、文档、视频项目卡片由用户主动读取，显示真实列表或错误，不伪造进度。没有任意脚本、URL 或自动业务写入能力。

首页保留聊天/工作模式及原 Logo；历史只在侧栏显示；输入区采用上下布局、标准 SVG 发送/停止，模型入口打开现有顶部菜单。

下一阶段：真实模型输出抽样、完整动态数学组件、文档逐页预览、在卡片内进行批量审核及任务控制、自动资源检索及流式输出。现有轮询不等同 token 流。
