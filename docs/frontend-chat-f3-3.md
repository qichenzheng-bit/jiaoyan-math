# F3.3 聊天界面

F3.2 CI 已通过。沿用 F2.1 数学、Markdown 与白名单交互卡片；优化正文宽度、独立滚动、用户气泡、移动端操作图标及桌面悬停/键盘焦点。真实题库资源按 ID 获取，复用 ResourceSections，答案解析默认折叠。原会话读取错误局部重试，生成状态轮询失败保留现有回答并继续同步。阻止会话加载失败时发送为新对话；并发提交保护，首次创建成功但发送失败保留会话 ID 与草稿。重新生成使用现有 rewind_id 分支接口，复用原用户正文、附件与保存的资源引用，使用当前模型，明确不复用未保存的原检索词，确认后创建分支而非覆盖。编辑原消息前保护现有未发送内容。不新增后台接口、真正流式能力或历史分页；现有完整会话读取不变。新增回归断言，待 CI 和真机验收。未部署。

补充覆盖实际分支请求参数及失败读取后的重试；读取中的会话允许离开并取消旧请求。题库搜索增加180ms防抖。
