# F4.7 教学作品中心：基础设施及自动接入

新增作品、版本、文件三张表与待匹配书衣表，复用 files/file_references 与备份体系。长期 PDF 通过 generated/ 硬链接脱离临时队列六小时过期机制。

第二批接入 PDF worker 成功回调，完整、选章、选题、选页、答案/题目版按逻辑版本分别管理。书衣只匹配同一内容及排版指纹；先导出的书衣独立暂存，后续匹配正文才进入同一正式版本，不覆盖旧正文。新书衣在正文已有时创建新正式版本，保留上一个版本。重复内容不创建新版本。入库异常仍可从原队列下载成功生成的 PDF，并明确提示重新导出。

旧版本清除引用；定期扫描仅由作品服务创建的 generated 文件，先标记待清理并等待一小时，再在备份共享锁保护下写持久化墓碑，随后删除实际文件。任一其他引用均阻止清理。已生成但事务异常遗留的无数据库记录硬链接需另行核对，不自动扫盘删除。

本批新增隔离测试；仍需 CI/实际 PDF 队列联调。待完成：视频旧作品库联动、完整前端、版本恢复、删除管理、发布商品引用、快照图片持久化保护及生产部署。
