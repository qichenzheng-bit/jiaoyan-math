# F4.7 教学作品中心：第一批基础设施

基于 F4.6 主分支，新增作品、版本、文件三张表，复用现有 files/file_references 和备份体系。长期成品使用 generated/ 下的硬链接，不受 .pdf-jobs 六小时过期清理影响。注册在管理员锁与同一数据库事务内完成，版本保留最新两个，内容和排版指纹相同则复用当前版本。

本批提供内部 PDF 正文注册服务、受登录保护的分页列表/详情/文件读取 API，以及独立 SQLite 测试。尚未把注册服务接入 PDF 队列完成回调；也未接入视频、印刷封面、章节/选页导出、前端和商品发布。旧版本只移除本作品版本引用，物理文件清理须在备份锁、引用检查、持久化清理标记完成后单独实现，避免误删。此分支不部署至生产环境，待后续完成及 CI 验证。
