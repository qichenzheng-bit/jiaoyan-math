# 微光数学前端设计规范（第一版）

基于 01 阶段人工反馈，整体替换测试型页面的视觉和布局，保留原 API、登录方式及数据库结构。

- 视觉：暖灰底、墨绿强调色、克制边框与阴影、清晰文字层级。使用原版微光数学 Logo：从 weiguang-math-V5 的 app/frontend/logo.svg 与 logo-dark.svg 原样复制，分别适配浅色与深色背景，不重绘。来源提交 849cb7f2dd4fa54aad910bfdb162840a5f713f9d。
- 桌面：固定分组侧栏、面包屑、全局 AI 面板，统一内容最大宽度。
- 手机：常用入口底部导航，全部功能从抽屉进入；不要求横向滚动。
- 首页：真实文件统计及操作记录，未开发业务明确标识，不填充虚构数据。
- 登录、文件、公式、设置页面共用颜色变量、按钮与输入框；支持浅色、深色、跟随系统及减少动效。
- 后续资源中心、教研编辑器、作品等复用上述规范，不再创建独立的临时样式。

验收：GitHub CI 构建通过、实际手机/桌面布局、登录退出、文件操作、主题切换、公式实时预览。此次仅修改前端，不修改数据库。未完成实际浏览器视觉回归测试。
