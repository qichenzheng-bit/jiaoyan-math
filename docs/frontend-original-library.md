# F3.4 原始资料库（增量）
独立原始资料库由现有非生成文件索引自动提供；上传沿用SHA256去重。持续工作加号支持选择库内多份资料。跨会话按文件ID共享批次、核对与入库进度，重叠识别限制跨会话生效。自然语言全文件名或完整去扩展名匹配，歧义要求选择；不是完整AI语义规划。完成以已生成文档中对应草稿UID均转成正式资源引用且覆盖全文件单位数为保守依据，不把核对等同入库。支持批量移入回收区、恢复，保护其他引用和待审核/运行任务，保留历史。暂未物理删除或释放空间：原文件备份和恢复契约要求所有登记文件存在，后续需独立墓碑迁移与协调删除协议。修复0020三个表缺失的备份导出清单，保留全量恢复校验。新增跨会话和回收区集成测试，待CI。未部署。

兼容旧格式2备份：仅允许旧快照完整缺少三个工作表导出；恢复时核对实际表清单，当前备份仍要求全部工作表。

补强：资料库明确区分已识别、已核对、已入库，完成需真实登记历史及有效正式引用；归档仍保守保护未完成任务。支持中文一至十页指令，并补充录入首页直接入口及回归断言。

## 逐题页码定位与跨批次文档
工作PDF整理允许AI返回各字段的物理页建议，严格限制在当前批次页码内；人工确认页码独立保存、审核后持久化，切换条目自动翻页。未知页码不伪造，暂无页内坐标及跨文件字段定位。手机端原文/编辑区域独立滚动，可调整原文视口高度。录入文档支持显式选择同一原始文件已转换文档并按版本追加，不覆盖此前块及快照，仍遵守200块/总字数限制；来源接口保留各批次来源及条目UID，兼容原字段。未实现跨文件题目答案语义匹配或永久物理清理。待CI。

补充集成测试：模拟两页PDF提取与AI响应，检查页码边界、人工确认、目标版本冲突、跨批次追加、原块完整及重复请求幂等。真实OCR与模型效果仍需人工验收。
