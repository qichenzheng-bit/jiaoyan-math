# F3.4 持续资料工作 — 基础阶段
新增独立的持久化工作会话、文件关联、明确范围的识别批次，迁移 0020 非破坏性。原有快速录入仍可用。一次选择多个文件（每次最多20个，原存储大小限制不变），文件类型按服务端实际检测。每批PDF最多10物理页，逐页请求、每页结果落库；文字失败时在OCR可用时尝试单页OCR。失败保留进度并显式重试，不自动创建下一批。每份文件上一批必须核对后才能开始不重叠的新批。核对后的文本通过现有 AI 整理接口进入原审核流程；工作批次与初始任务原子关联，未改正式入库校验。历史工作从侧栏恢复。初步自然语言只解析明确文件名称+继续识别N页并填入待确认范围；未使用模型自由识别指令。PDF原页以有界服务端PNG渲染，手机上下、桌面左右对照本批原文，AI审核页同步提供本批物理页浏览；没有逐题坐标或自动定位。Word原版式仍需下载。尚未实现跨批次/多文件答案关联、同一文档追加、审核阶段逐题来源、批次超字数拆分、重识别已核对批次、已入库页统计或独立工作对话消息。此提交为F3.4基础实现，不代表完整验收。未部署。
