# M10–M13 基础台账
参考旧 assets.js、publish.js、publish_specs.py、model_publish.py、qiandao.js，使用类型校验的统一工作室表和不可变版本记录。素材分类/收藏/标签、文件关联保护、作品内容及教研文档引用、发布状态/文案/真实链接、人工观察日期和播放点赞评论、签到账户别名及日记录。所有账号均不保存凭据，未实际执行签到、积分查询或发布。平台尺寸仅旧版模板预设，不宣称当前官方规范。素材分类和收藏暂按当前分页筛选；作品关联选择最多100项，历史版本最多100项。图文/课件暂为内容草稿，不是完整编辑器；自动发布、平台数据回流、自动签到、提醒调度、备份界面及清理仍待实现。旧视频继续独立。真实浏览器与CI待验证。

补充：基础函数绘图使用六类固定函数及参数控制，不执行任意表达式；PNG可下载、上传并创建作品记录。封面使用旧版平台尺寸与安全区、原Logo、可调文字/颜色/位置，PNG导出不包含辅助线；不支持公式渲染、拖拽层、背景图片及可重新载入的画布编辑。图文和课件入口仅草稿，不标记为完整迁移。
