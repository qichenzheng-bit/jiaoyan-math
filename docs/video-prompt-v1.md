## 第二批
- 题库原始、转载、改编来源及核验状态按真实关联提取，优先唯一可信原始来源，不混拼多份试卷信息。新增项目在本地保存 opening_source、知识标签及来源数量，提交生成时通过任务上下文传入独立引擎；不修改旧题库数据。历史项目尚无新字段，保持兼容，不擅自补造。
- 42个示例目录条目已具备：10类完整课堂参考（5类继承、5类新增草稿），20类专项参考，12类技术参考。新增完整草稿仅做 Python AST 测试，全部尚需实际引擎接口与成片验收；三维示例为投影示意，真实三维支持尚未确认。
- 仍待完成：附件传输、入队级完整提示词快照、微调补充要求继承、运行目录安全升级及实际成片验收。


## 开场调整（用户确认）
取消来源绑定及来源播报。保留原有来源管理和项目快照；生成时仅按需传递知识标签，不以来源字段或新适配器元数据能力作为生成前提。用户补充提示词仍遵循原有快照能力检查。开场规范及相关示例同步更新。布局数值暂保持原值，等待布局设计确认。


## 第三批
- 布局调整已提交，200px字幕仅候选，生产仍240px，需独立渲染测试。
- 生成入队前固定教学/修复/编辑规则及选中示例，同任务修复复用。新成片契约记录生成任务编号，微调依据当前成片继承原课规则及补充要求，用户本次明确指令优先。历史成片无编号则用当前编辑规范。尚需实际独立引擎联调。
